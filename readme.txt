Redirects the user to the overview page after hitting the save/publish post button in Gutenberg editor.

== Description ==
This plugin hooks into the Gutenberg editor JavaScript and reacts to the savePost action.

It waits until the ajax calls are finished and redirects the user back to the post types overview page when no error occurs.

The plugin does not need to be configured.

== Installation ==
Download, activate and you are ready to go.

== Frequently Asked Questions ==
Q: Does this work with custom post types?
Yes, it does.
